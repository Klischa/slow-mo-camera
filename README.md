# 🎥 Slow-Mo Camera & Video Studio (Android 14 / Camera2 API)

Нативное Android-приложение для профессиональной высокоскоростной съёмки Slow-Motion (120/240 FPS), полноразмерной фотосъёмки, таймлапса и расширенного пост-продакшн видеоредактора.

Специально оптимизировано для чипсетов **MediaTek Helio G99** (включая **Infinix Note 30**, камера 64MP) с поддержкой Root-разблокировки и автоматической ориентации.

---

## ✨ Возможности приложения

### 1. 📷 Режимы съёмки
* **SLOW-MO Видео (120/240 FPS):**
  * **HFR (High-Frame-Rate):** Захват на 120/240 fps, сохранение с частотой контейнера **30 fps** (видео сразу замедлено в 4x / 8x раз).
  * **HSR (High-Speed Recording):** Захват и сохранение с полной частотой 120/240 fps.
* **ФОТО:** создание качественных снимков максимального разрешения сенсора.
* **ТАЙМЛАПС:** ускоренная интервальная съёмка.
* **БУФЕР (Запись в прошлое):** непрерывная кольцевая буферизация последних секунд (Retroactive recording) — сохранение нужного момента нажатием одной кнопки.
* **Снимок во время видео:** отдельная кнопка фотосъёмки во время активной видеозаписи (Snapshot ImageReader).
* **Автоматический захват движения (Motion Detection):** умный старт Slow-Mo записи при обнаружении движения в кадре.

### 2. 🎛 Ручные PRO-настройки
* **ISO / Чувствительность:** автоматический или ручной режим (100 – 3200+).
* **Выдержка (Shutter Speed):** от 1/4000s до 1/30s.
* **Фокусировка:** непрерывный автофокус + **Tap-to-Focus** (нажатие на любую точку кадра для точечного фокуса и замера экспозиции) + ручной слайдер фокусного расстояния.
* **Баланс белого (WB):** Авто, Солнце, Облачно, Лампа накаливания, Флуоресцент.
* **Экспокоррекция (+/- EV).**
* **Плавный Zoom щипком (Pinch-to-zoom):** масштабирование во время превью и записи, двойной тап для сброса на 1.0x.

### 3. 🎬 Встроенный видеоредактор (Video Studio)
* **Импорт любого видео** из Галереи или памяти устройства.
* **Обрезка (Trim):** визуальный таймлайн с маркерами начала и конца.
* **Регулировка скорости:** плавный выбор и пресеты (**0.125x, 0.25x, 0.5x, 1.0x, 2.0x**).
* **Наложение музыки:** добавление фонового трека из библиотеки устройства.
* **Управление оригинальным звуком:** отключение или сохранение исходной дорожки.
* **Предпросмотр в реальном времени** перед сохранением.
* **Экспорт:** в форматах **MP4 (H.264)** и **WebM (VP9)** через Media3 Transformer.

### 4. 🗂 История записей и Шаринг
* Встроенная история всех созданных видео и фото с миниатюрами, хронометражем и датой.
* Быстрая отправка в мессенджеры и соцсети через системный **Android Share Intent**.

### 5. 🔄 Полная автоориентация
* Адаптивный интерфейс и превью при любом положении устройства (портретный, альбомный, обратный альбомный режим).
* Корректная запись фронтальной и основной камеры с зеркальной компенсацией.

## 📱 Root & MediaTek Helio G99 (Infinix Note 30)

Для чипсетов MediaTek доступна разблокировка 120/240 FPS через Root:
1. Готовый Magisk-модуль: **`Infinix_MTK_SlowMo_Unlock_Magisk.zip`** (в разделе Releases).
2. Выполнение скрипта через `su` / Termux:
```bash
su
curl -sL https://raw.githubusercontent.com/Klischa/slow-mo-camera/main/unlock_mtk_fps.sh | sh
```
